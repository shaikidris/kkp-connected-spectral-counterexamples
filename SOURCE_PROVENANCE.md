# Source provenance

This package contains substantive graph and spectral proof source. The
authoritative submission snapshot will be the clean, reviewed commit supplied
to intake. No submission commit has been created.

| Role | Repository | Commit |
|---|---|---|
| Extracted BN spectral support | ShengtongZhang-alt/BN | 5f4741254398424b730c9a893220a51e1cd829c5 |
| Mathlib dependency of this package | leanprover-community/mathlib4 | dd56d02cb7a58fa066c4a2c7fddec3cbb59ae8df |

`KKP.Bridge`, `KKP.Witness`, `KKP.Certificate`, `KKP.Compression`, and
`KKP.SpectralWitness` are the graph counterexample proof. `BN.Basic.Inner`,
`BN.Basic.Spectrum`, `BN.Definition`, `BN.Spectral.Interlace`, and
`BN.Spectral.Variational` supply reused spectral support. Source hashes and
build receipts are retained in the canonical research workspace.
